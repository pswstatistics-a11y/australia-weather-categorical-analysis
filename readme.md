# 호주 기상 데이터를 활용한 구조적 다중공선성 제어 및 강수 예측 로지스틱 모델

호주 기상청 데이터를 활용하여 내일의 강수 여부(1 또는 0)를 이진 분류하기 위해, 인자분석을 통한 차원 축소와 삼각함수를 이용한 풍향 변환을 적용한 로지스틱 회귀 모델 프로토타입 저장소입니다.

## 주요 방법론 및 변수 처리 명세

### 1. 반복 측정 지표의 다중공선성 제어를 위한 인자분석
* 기온, 습도, 기압, 풍속 등 기상 변수가 오전 9시와 오후 3시 두 번씩 반복 측정됨에 따라 발생하는 구조적 다중공선성 문제를 해결하기 위해 탐색적 인자분석(최대우도법 및 Varimax 직교회전)을 적용했습니다.
* 각 시간대별 지표들을 단일 잠재 인자 점수(Factor Scores)로 축약하여 최종 입력 변수로 전환함으로써 모델의 다중공선성 위험을 제거했습니다.

### 2. 풍향 데이터의 주기성 제어를 위한 삼각함수 좌표 사상
* 풍향 데이터는 0도와 359도가 연속되는 원형 구조를 가지므로 불연속성 경계면에서의 수학적 왜곡을 방지하기 위해 풍향의 방위각을 $\cos(\theta)$와 $\sin(\theta)$의 2차원 성분으로 변환하여 모델에 투입했습니다.
* 도시명과 날짜 데이터는 고차원 희소성을 방지하기 위해 각각 광역 단위의 지역분류 및 계절 변수로 리코딩하여 통제 변수로 결합했습니다.

### 3. 최종 모형 적합 및 임계값 최적화 (Out-of-sample 검증)
* 전체 데이터를 8:2로 분할하여 학습 데이터로만 로지스틱 회귀 모델(`glm`)을 적합하고 테스트셋으로 평가를 수행하여 **AUC = 0.833**의 일반화 성능을 확인했습니다.
* 예측 확률값의 분포가 0.1~0.2 구간에 압착된 클래스 불균형 특성으로 인해 기존 디폴트 임계값(0.5) 하에서는 민감도가 유실되는 한계가 존재하여, F1-Score를 기준으로 임계값 그리드 서치를 수행했습니다.

| 평가지표 | 기존 모델 (Threshold = 0.5) | 최적화 모델 (Threshold = 0.32) | 수리적 거동 해석 |
| :--- | :---: | :---: | :--- |
| **F1-Score** | - | **0.5917** | 불균형 환경 하에서의 종합 변별력 확보 |
| **정확도 (Accuracy)** | 83.17% | **0.8044** | 다수 클래스 편향에 기댄 착시 제거 후 정교화 |
| **민감도 (Sensitivity)** | 42.77% | **0.6311** | 경계면 조정을 통해 실제 강수일 인출력 방어 |
| **특이도 (Specificity)** | 94.87% | **0.8546** | 모델의 과도한 '비 안 옴' 예측 성향 제어 |

* **결론**: 임계값을 0.32로 하향 조정함으로써 소폭의 정확도와 특이도를 양보하는 대신, 실무 예측 목적에 필수적인 민감도를 63.11%까지 끌어올려 통계적 의사결정 균형점을 도출했습니다.
